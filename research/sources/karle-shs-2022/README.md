# Related hardware boundary — KArLE sample handling

J. Tighe Costa et al., **Development and Testing of a Sample Handling System for
In-Situ Lunar Geochronology with KArLE**, IEEE Aerospace Conference, 2022.
Credit: authors / Honeybee Robotics / NASA GSFC. Research reference copies.
[Primary author-hosted paper](https://www.tighecosta.com/_files/ugd/8865be_78ab5b9dc0f34c1897151e60748e2ae1.pdf).
Saved October 27, 2026; original pages 1 and 4 rendered once as JPG, no PDF committed.

Page 4 describes Hall sensors, a 1024-count optical quadrature encoder and a
carousel home limit switch; figures 10/12 are CAD, 11/13 physical hardware.
DrACO is cited for retainer/elevator heritage. This **does not establish** these
sensor types or flight circuits on Dragonfly. No geometry or wire copied from
this lunar system. Saved to prevent rediscovering/misapplying this related source.
