# Connector Standards: D-sub and Micro-D Sizes

Space electronics boxes use standard military connectors, so their published sizes work as a
ruler in photographs and give the drawn connectors their real proportions.

| File / link | What it gives |
|---|---|
| `glenair-micro-d-mil-dtl-83513-table.jpg` | Glenair, *MIL-DTL-83513/08 & /09 Micro-D pre-wired connectors*, Table I ([PDF](https://cdn.glenair.com/micro-d/pdf/l/8-and-9.pdf)): overall length 20.02 mm (9-way), 23.83 (15), 27.64 (21), 30.18 (25), 33.99 (31), 37.80 (37), 36.53 (51) |
| [TE shell size B listing (RS)](https://uk.rs-online.com/web/p/d-sub-connectors/7183887) | 25-way D-sub (shell B), length 53.42 mm |
| [TE shell size A listing (RS)](https://uk.rs-online.com/web/p/d-sub-connectors/4543488) | 15-way D-sub (shell A), length 39.2 mm |

D-sub flange width (about 12.5 mm) and the 9-way shell E length (about 30.8 mm) are the
standard MIL-DTL-24308 sizes; the controlling document is MIL-DTL-24308 (DLA ASSIST).

Used by parts 11 (PSU face: 25-way and 9-way D-subs) and 12 (IEM: Micro-Ds).
