# NASA source imagery

These originals are kept for reproducibility; only optimized files in `dist/assets/exterior/`
are published. Credits, public download links and processing steps are in that folder's README.

- `dragonfly-landscape.mp4`: NASA/APL Dragonfly landscape animation.
- `landscape-frame-9.png`: the unmodified frame extracted at 9 seconds.
- `landscape-contact.jpg`: 0/3/6/9-second frame selection sheet.
- `saturn-pia17474.jpg`: original Cassini Saturn mosaic.
- `titan-pia17180.jpg`: original Cassini Titan image.
- `dragonfly-departure.jpg`: alternate NASA/APL composition reviewed but not used.
  [Source and credit](https://science.nasa.gov/image-detail/dragonfly-departurebegin/),
  [original JPEG](https://science.nasa.gov/wp-content/uploads/2023/11/dragonfly-departurebegin.jpg).
